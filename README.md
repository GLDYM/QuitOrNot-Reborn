# QuitOrNot-Reborn

## Introduction

`QuitOrNot-Reborn` is a [`QuitConfirm`](https://github.com/CaaMoe/QuitConfirm) fork.

As a client-side mod, it pops up a confirm screen | toast to avoid mistakenly quitting the game.

## Features

* Confirm by Screen | Toast
* Multiple Optional Confirm Screen Styles
* Highly Configurable

## How 2 Install

NeoForge 26.1.2: Install the mod, no extra dependency needed.
